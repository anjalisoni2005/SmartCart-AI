# SmartCart AI

An AI-inspired smart shopping assistant built for the **AI Growth & Agentic Commerce** track.

## Problem
Online shoppers often face too many choices and spend time comparing products. Businesses also need better ways to personalize recommendations.

## Solution
SmartCart AI asks for the shopper's needs and budget, analyzes those inputs, and ranks suitable products. The demo focuses on personalized recommendations and an easy conversational shopping experience.

## Features
- Personalized product recommendations
- Budget-aware ranking
- Simple AI-style matching logic
- Responsive web interface
- No database or API required for the demo

## How to run
Download or clone the repository and open `index.html` in a web browser.
